# Teleport Blocker

Removes the click options from teleports, for chunk-locked and other
self-restricted accounts. The spell icon or the item stays where it is and only
its menu entries go.

Jewellery is blocked on the worn item, in its submenu and in the rub
dialogue, by key as well as mouse.

| Source | Toggles |
| --- | --- |
| Standard spellbook | 12 |
| Minigames window | 21 |
| Rat pit dialogue | 4 |
| Ancient spellbook | 9 |
| Lunar spellbook | 9 |
| Canoes | 11 |
| Ring of dueling | 4 |
| Games necklace | 5 |
| Amulet of glory | 4 |
| Ring of wealth | 4 |
| Necklace of passage | 4 |
| Combat bracelet | 4 |
| Skills necklace | 6 |
| Slayer ring | 6 |
| Digsite pendant | 3 |
| Burning amulet | 3 |

The two master toggles start on and cover their whole section. Untick one and
nothing below it is blocked until you tick what you want. The ancient, lunar and
canoe sections have no master and start off entirely.
