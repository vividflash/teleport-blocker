# Teleport Blocker

Removes the click options from standard spellbook teleports for chunk-locked
and other self-restricted accounts. The spell icon stays in the book, only its
menu entries go. Each of the 13 teleports has its own toggle, all on by
default, and blocking a spell removes its alternate destinations too, such as
Varrock's Configure or the Group Ironman entries on Teleport to House.
